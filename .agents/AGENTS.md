# Workspace Rules

- 所有的回答和沟通必须全部使用中文。
- 1. 使用简体中文回答。
- 2. 项目代码中，除了文件名、注释和字符串（可以保留英文），尽量使用中文。
- 3. 变量和函数命名优先使用英文，除非业务逻辑强依赖中文。
- 4. 优先使用中文关键词和注释，但对于技术概念，如无标准中文翻译或已有广泛接受的英文术语，可使用英文。
- 5. 代码注释和文档应尽量采用中文，便于团队理解。
- 6. UI 文本（包括标题、按钮、提示信息等）应优先采用中文，保持界面的一致性。
- 7. 在代码提交信息（Commit Messages）中，优先使用中文描述改动内容。
- 8. 提交时，如果需要描述技术细节，可以使用中英混合，但应确保中文为主。
- 9. 对于外部技术文档和标准，如果它们已有广泛接受的中文翻译版本，应优先引用中文版本；否则使用英文。
